# 소 산지가격 — 관리자 입력 안내 (파일 1개로 관리)

공식 오픈API가 없어 **수동 입력**으로 운영합니다. **`prices.json` 파일 하나**만 관리하면 됩니다.
(날짜별 파일을 여러 개 만들 필요 없음 — 페이지가 이 파일 하나에서 날짜조회·추이·폴백을 모두 계산합니다.)

## 어디서 가격을 보나
공식 조회 화면(다봄): https://www.ekapepia.com/v3/price/livestock/cow/producer.do
- **가축시장가격(송아지·큰소)** 와 **농가수취가격(한우/육우 600㎏)**, 단위 **천원/마리**.

## prices.json 구조
```json
{
  "unit": "천원/마리",
  "source": "축산물품질평가원 축산유통정보 다봄·농협중앙회",
  "latestDate": "2026-09-21",
  "updatedAt": "2026-09-21T18:00:00+09:00",
  "data": {
    "2026-09-18": { "prices": { "largeCow600kg": {"price":6890,"previousPrice":6890}, ... } },
    "2026-09-21": { "prices": { "largeCow600kg": {"price":7042,"previousPrice":6991}, ... } }
  }
}
```

## 새 발표일 추가하는 법 (3가지만)
1. `data` 안에 **새 날짜 한 줄** 추가:
   `"2026-09-22": { "prices": { ...9개 항목... } }`
   - `price` = 그날 가격, `previousPrice` = 다봄 화면의 직전 발표가(증감 계산용). 자료 없으면 `null`.
2. 맨 위 **`latestDate`** 를 새 날짜로 변경.
3. **`updatedAt`** 를 갱신.
→ GitHub에 저장(commit) 하면 반영. **오래된 날짜는 지우지 말고 그대로 두면** 추이 그래프가 길어집니다.

## 항목 키 ↔ 화면 이름
| 키 | 화면 이름 | 그룹 |
|---|---|---|
| largeCow600kg | 한우 큰 암소 600㎏ | 가축시장 |
| femaleCalf4to5 | 한우 암송아지 4~5개월령 | 가축시장 |
| maleCalf4to5 | 한우 수송아지 4~5개월령 | 가축시장 |

| maleCalf6to7 | 한우 수송아지 6~7개월령 | 가축시장 |
| hanwooAverage600kg | 한우 평균 600㎏ | 농가수취 |
| hanwooSteer600kg | 한우 거세우 600㎏ | 농가수취 |
| hanwooBull600kg | 한우 비거세우 600㎏ | 농가수취 |

## 파일이 너무 커지면?
- 하루 9개 항목뿐이라 1년치도 수십 KB 수준이라 문제없습니다.
- 그래도 줄이고 싶으면 아주 오래된 날짜(예: 2년 이전)만 지우면 됩니다. 최근치만 있어도 동작합니다.

## 값 없는 항목
- `price`를 `null` 로 두면 화면에 **자료 없음** 으로 표시됩니다. **가짜 숫자는 넣지 마세요.**

## 자동화(선택)
공식 산지가격 오픈API가 생기면 AWS 배포키트로 자동수집 전환 가능. 그 전까지는 이 방식이 가장 간단합니다.
