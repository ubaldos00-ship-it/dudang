# 소 산지가격 — 관리자 입력 안내 (AWS 불필요)

공식 오픈API가 없어 **수동 입력** 방식으로 운영합니다. 파일 숫자만 채워 GitHub에 올리면 페이지에 바로 반영됩니다.

## 어디서 가격을 보나
공식 조회 화면(다봄): https://www.ekapepia.com/v3/price/livestock/cow/producer.do
여기서 **가축시장가격(송아지·큰소)** 와 **농가수취가격(한우/육우 600㎏)** 을 확인하세요. 단위: **천원/마리**.

## 어떻게 입력하나
1. `data/cattle_price/latest.json` 을 연다.
2. 각 항목의 `price`(이번 발표가), `previousPrice`(직전 발표가)를 **숫자**로 채운다. (자료 없으면 `null` 그대로)
3. `dataDate`(발표일 `2026-09-24`), `updatedAt`(입력시각, 예 `2026-09-24T18:00:00+09:00`)을 채운다.
4. GitHub에 저장(commit) → 몇 분 뒤 페이지에 반영.

## 날짜별 이력·추이 그래프를 쓰려면(선택)
- 발표일마다 같은 폴더에 **`2026-09-24.json`** 처럼 그 날짜 파일을 하나씩 더 저장하면,
  페이지의 날짜 이동(◀ ▶)과 **가격 추이** 그래프가 동작합니다.
- 그리고 **`latest.json`** 은 항상 가장 최근 파일과 동일하게 유지하세요.

## 항목 키 ↔ 화면 이름
| 키 | 화면 이름 | 그룹 |
|---|---|---|
| largeCow600kg | 한우 큰 암소 600㎏ | 가축시장 |
| femaleCalf4to5 | 한우 암송아지 4~5개월령 | 가축시장 |
| maleCalf4to5 | 한우 수송아지 4~5개월령 | 가축시장 |
| femaleCalf6to7 | 한우 암송아지 6~7개월령 | 가축시장 |
| maleCalf6to7 | 한우 수송아지 6~7개월령 | 가축시장 |
| hanwooAverage600kg | 한우 평균 600㎏ | 농가수취 |
| hanwooSteer600kg | 한우 거세우 600㎏ | 농가수취 |
| hanwooBull600kg | 한우 비거세우 600㎏ | 농가수취 |
| beefCattleAverage600kg | 육우 평균 600㎏ | 농가수취 |

## 입력 예시 (2026-09-24.json)
```json
{
  "dataDate": "2026-09-24",
  "updatedAt": "2026-09-24T18:00:00+09:00",
  "prices": {
    "largeCow600kg":  { "price": 7042, "previousPrice": 6991 },
    "femaleCalf4to5": { "price": 3260, "previousPrice": 3255 },
    "hanwooAverage600kg": { "price": 8361, "previousPrice": 8300 }
  }
}
```
※ 값을 넣지 않은 항목은 자동으로 `자료 없음` 으로 표시됩니다. 임의의 가짜 숫자는 넣지 마세요.

## 나중에 자동화하고 싶으면
공식 산지가격 오픈API가 생기면, 앞서 드린 AWS 배포키트로 자동수집으로 전환할 수 있습니다. 그 전까지는 이 수동 방식이 가장 간단합니다.
