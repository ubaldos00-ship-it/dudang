======================================================

■ 무엇이 바뀌나 (한 줄)
  질문 하나로 여러 자료를 "함께" 조회해 한 답으로 엮어줍니다.
  예) "비육우 거세 24개월이면 지금 산지가격으로 팔면 얼마야? 그리고 조사표에 대소동물 판매내역에 조사표 만들어죠."
   → ① 참고체중 580kg(한우연구소 2013) ② 거세우 산지가격(기준일 명시)
      ③ 참고 판매금액 약 8,639,100원(=1kg단가×580kg, 서버계산)
      ④ ② 대·소동물 판매 조사표 카드까지 한 번에 표시.

■ GitHub(ubaldos00-ship-it/dudang)에 덮어쓸 파일 2개
  1) js/chatbot.js         (v115)
  2) service-worker.js     (캐시 v104 — 새 chatbot.js 반영용, 꼭 함께 올리기)

  ※ 두 파일을 같은 경로(js/ 포함)에 그대로 덮어쓰면 됩니다.
  ※ service-worker.js를 안 올리면 기기에 옛 chatbot.js가 남아 바로 반영 안 될 수 있음.

■ 반드시 함께: AWS Lambda v23 배포 (서버쪽)
  통합조회의 '숫자 계산(참고체중·금액·통계 조회)'은 서버(Lambda)가 합니다.
  aws_dudang_ai/lambda_dudang_ai.mjs (v23) 를 AWS Lambda 콘솔 dudang-ai-chat 함수에
  붙여넣고 [Deploy] 하세요. (메모리 512MB·타임아웃 30초 권장 — 기존 설정 그대로면 OK)
  Lambda를 Deploy 안 하면 참고체중·금액·조사표 통합이 작동하지 않습니다.

■ 클라이언트 변경 상세 (chatbot.js v115)
  - looksCompound() 추가: 가격·금액·조사표·설명·비교가 섞인 '복합질의'를 인식.
    · 순수 통계질의(예 "25년 한우 비육우 소득")만 빠른 통계모드(stats)로.
    · 복합질의(가격/조사표/설명 섞임)는 통합(일반)경로로 → 서버가 여러 자료 동시 조회.
  - 일반답변에 서버가 만든 조사표(structured)가 오면 조사표 카드도 이어서 표시.
  - 참고자료 링크에 ⚖️참고체중·📈공표통계(+KOSIS 원문 URL) 추가.
